# 第 5 课：接入高德地图（httpx 服务层）

**目标**：让后端拿到**真实世界的数据**：景点 / 酒店 / 餐厅（POI 搜索）和天气预报。这一课完全不涉及大模型，就是写一个靠谱的 HTTP 客户端，学会四件事：

1. **httpx**：Python 版的 axios。
2. **服务层**：把"怎么调高德"封装起来，路由只负责收参数、返回结果。
3. **依赖注入 `Depends`**：路由的依赖由 FastAPI 负责创建并传进来，方便测试时替换。
4. **全局异常处理器**：上游出错时，统一转成格式规整的错误响应。

对应：参考仓库 `backend/app/planner/amap.py`（HTTP 版）。书里第 13.4 节用的是 MCP 方式，第 8 课再讲。

> 本课代码已用 `httpx.MockTransport` 模拟高德的真实返回格式做过测试：正常数据、缺失坐标、字段为空数组、业务错误、Key 未配置五种情况都符合预期。第一版代码在错误信息里泄露了 Key，是在第 9 课的测试中发现并修复的，下面第四个坑讲的就是这个问题。**真实请求需要你自己的高德 Key**（我这边没有 Key，没法替你实测）。

## Step 0：申请高德 Key

1. 登录 [高德开放平台](https://console.amap.com/dev/key/app)，进入"应用管理 → 我的应用 → 创建新应用"。
2. 添加 Key 时，**服务平台选"Web 服务"**（不是"Web 端(JS API)"，那个是第 10 课前端地图用的）。
3. 填进 `backend/.env`：

```bash
AMAP_API_KEY=你的Web服务Key
```

先用浏览器直接验证 Key 是否可用（把 `你的KEY` 换掉）：

```
https://restapi.amap.com/v3/weather/weatherInfo?city=北京&extensions=all&key=你的KEY
```

返回 `"status":"1"` 就说明 Key 可用。

## 高德 API 的四个坑（代码里都处理了）

| 坑 | 表现 | 处理 |
|---|---|---|
| 业务错误也返回 HTTP 200 | Key 错了照样是 200，body 里 `"status":"0"` | 检查 `status != "1"` 时抛出 `AmapError` |
| 空字段是 `[]`，不是 `""` | `"address": []`、`"tel": []` | `as_text()` 统一转成字符串 |
| 坐标是字符串 | `"location": "116.397,39.909"`（经度在前） | `parse_location()` 拆成 `Location` |
| **Key 在 URL 里** | httpx 的异常信息会带上完整 URL，其中就有 `key=你的Key` | 错误信息只保留状态码和异常类名，**绝不把原始异常直接拼进返回给前端的消息** |

```python
class POIInfo(BaseModel):
    """一个地点（Point of Interest）：景点、酒店、餐厅都是 POI"""

    id: str = Field(..., description="高德 POI ID")
    name: str = Field(..., description="名称")

    address: str = Field(default="", description="地址")
    district: str = Field(default="", description="所在区县")
    location: Location = Field(..., description="经纬度")
    tel: str = Field(default="", description="电话")
    rating: float | None = Field(default=None, description="评分，可能没有")

# 泛型响应外壳：ApiResponse[list[POIInfo]]、ApiResponse[list[WeatherInfo]]……
# class ApiResponse[T] 是 Python 3.12+ 的泛型语法，相当于 TS 的 interface ApiResponse<T>

    message: str = ""
    data: T | None = None
```

## Step 2：高德客户端 `app/services/amap_client.py`

```python
"""高德地图 Web 服务 API 客户端（直接走 HTTP，不经过大模型）

官方文档：https://lbs.amap.com/api/webservice/summary
本课用到两个接口：
  - 关键字搜索 POI：GET /v3/place/text
  - 天气查询：    GET /v3/weather/weatherInfo
"""

from functools import lru_cache
from typing import Any

import httpx  # Python 的 HTTP 客户端，API 风格和 axios 很像；装 fastapi[standard] 时已经带上了

from app.config import get_settings
from app.models.schemas import Location, POIInfo, WeatherInfo

AMAP_BASE_URL = "https://restapi.amap.com/v3"


class AmapError(Exception):
    """高德调用失败时抛出的业务异常（自定义异常类，相当于 JS 的 class AmapError extends Error）"""


def parse_location(text: Any) -> Location | None:
    """高德返回的坐标是字符串 "116.397,39.909"（经度在前），转成 Location 对象"""
    if not isinstance(text, str) or "," not in text:
        return None  # 有些 POI 没有坐标，或者返回的是 []
    lng, lat = text.split(",", 1)  # split(",", 1)：最多切一刀
    try:
        return Location(longitude=float(lng), latitude=float(lat))
    except ValueError:  # 转 float 失败，或者超出经纬度范围（Pydantic 校验失败也是 ValueError 的子类）
        return None


def parse_float(value: Any) -> float | None:
    """高德的 rating/cost 可能是 "4.6"、""、[]，统一转成 float 或 None"""
    try:
        return float(value)
    except (TypeError, ValueError):  # 一次捕获多种异常，写成元组
        return None


def as_text(value: Any) -> str:
    """高德的一个坑：字段没有值时，返回的不是 "" 而是 []，统一转成字符串"""
    return value if isinstance(value, str) else ""


class AmapClient:
    def __init__(self, api_key: str, transport: httpx.BaseTransport | None = None):
        """
        api_key：高德 Web 服务 Key
        transport：只在测试时传入，用来模拟高德返回的数据，不发真实请求（第 11 课会用到）
        """
        if not api_key:
            raise AmapError("AMAP_API_KEY 未配置，请在 backend/.env 中填写")
        self.api_key = api_key
        # httpx.Client 相当于 axios.create({...})：复用连接，统一 baseURL 和超时
        self.http = httpx.Client(base_url=AMAP_BASE_URL, timeout=10, transport=transport)

    def _get(self, path: str, params: dict[str, Any]) -> dict[str, Any]:
        """所有请求的统一入口：带上 key、处理网络错误、处理高德业务错误"""
        try:
            # {**params, "key": ...} 是字典展开，相当于 JS 的 { ...params, key: ... }
            response = self.http.get(path, params={**params, "key": self.api_key})
            response.raise_for_status()  # HTTP 状态码不是 2xx 时抛出异常
        except httpx.HTTPStatusError as exc:  # 高德返回了 4xx/5xx
            # 注意：不要直接写 f"{exc}"！httpx 的异常信息里带着完整 URL，URL 里有 key=你的Key，
            # 这条信息会被返回给前端、写进日志，等于把 Key 公开了
            raise AmapError(f"请求高德失败: HTTP {exc.response.status_code}") from exc
        except httpx.HTTPError as exc:  # 超时、连不上……
            # type(exc).__name__ 只取异常类名，例如 ReadTimeout、ConnectError
            # raise ... from exc：保留原始异常链，排查问题时在服务端日志里能看到根本原因
            raise AmapError(f"请求高德失败: {type(exc).__name__}") from exc

        data = response.json()
        # 高德的另一个坑：业务失败时 HTTP 状态码照样是 200，要看 body 里的 status
        # status="1" 成功，"0" 失败，info 是错误原因（例如 INVALID_USER_KEY）
        if data.get("status") != "1":
            raise AmapError(f"高德返回错误: {data.get('info')}（infocode={data.get('infocode')}）")
        return data

    def search_poi(self, keywords: str, city: str, limit: int = 10) -> list[POIInfo]:
        """关键字搜索 POI，例如 keywords="博物馆", city="北京" """
        data = self._get(
            "/place/text",
            {
                "keywords": keywords,
                "city": city,
                "citylimit": "true",  # 只在指定城市内搜索
                "extensions": "all",  # 返回详细信息（包括评分、人均消费）
                "offset": limit,  # 每页条数
                "page": 1,
            },
        )

        results: list[POIInfo] = []
        for poi in data.get("pois", []):
            location = parse_location(poi.get("location"))
            if location is None:
                continue  # 没坐标的 POI 没法在地图上显示，直接丢掉
            biz_ext = poi.get("biz_ext") or {}  # `or {}`：值为 None 或 [] 时用空字典兜底
            results.append(
                POIInfo(
                    id=poi.get("id", ""),
                    name=poi.get("name", ""),
                    type=as_text(poi.get("type")),
                    address=as_text(poi.get("address")),
                    district=as_text(poi.get("adname")),
                    location=location,
                    tel=as_text(poi.get("tel")),
                    rating=parse_float(biz_ext.get("rating")),
                    cost=parse_float(biz_ext.get("cost")),
                )
            )
        return results

    def get_weather(self, city: str) -> list[WeatherInfo]:
        """查询未来几天（通常是今天起 4 天）的天气预报"""
        data = self._get("/weather/weatherInfo", {"city": city, "extensions": "all"})  # all = 预报，base = 实况
        forecasts = data.get("forecasts") or []
        if not forecasts:
            return []
        return [
            WeatherInfo(
                date=cast.get("date", ""),
                day_weather=cast.get("dayweather", ""),
                day_temp=cast.get("daytemp", "未知"),  # 是字符串 "25"，交给第 3 课写的 before 校验器转成 int
                night_temp=cast.get("nighttemp", "未知"),
            )
            for cast in forecasts[0].get("casts", [])
        ]


# 整个进程共用一个客户端（连接池可以复用），和 get_settings 一样用 lru_cache 实现单例
@lru_cache
def get_amap_client() -> AmapClient:
    return AmapClient(get_settings().amap_api_key)
```

> **为什么用 `httpx.Client` 而不是每次都 `httpx.get(...)`？**
> `Client` 会复用 TCP 连接（连接池），连续请求时省掉每次重新建连接、做 TLS 握手的开销。类比前端：`axios.create()` 出一个实例反复使用，而不是每次都 `new XMLHttpRequest()`。

```python
"""POI 搜索接口（替换第 2 课作业里的假数据版本）"""

from typing import Annotated

from fastapi import APIRouter, Depends, Query

from app.models.schemas import ApiResponse, POIInfo
from app.services.amap_client import AmapClient, get_amap_client

router = APIRouter(prefix="/poi", tags=["POI"])


# 注意这里用的是 def，不是 async def：
# httpx.Client 是同步阻塞的，写在 def 路由里，FastAPI 会自动把它放到线程池执行，不会卡住其他请求；
# 如果写成 async def 再调用阻塞代码，整个服务在等高德返回期间都处理不了别的请求
@router.get("/search", response_model=ApiResponse[list[POIInfo]], summary="关键字搜索 POI")
def search_poi(
    # Annotated[类型, 额外信息]：Query(...) 给查询参数加校验和文档
    keywords: Annotated[str, Query(min_length=1, max_length=30, description="关键词，例如 博物馆")],
    city: Annotated[str, Query(min_length=1, description="城市")] = "北京",
    limit: Annotated[int, Query(ge=1, le=25)] = 10,
    # 依赖注入：FastAPI 调用 get_amap_client() 并把结果传进来
    # 好处：路由不关心客户端怎么创建；测试时可以用 app.dependency_overrides 换成假客户端
    amap: AmapClient = Depends(get_amap_client),
):
    # 这里不用 try/except：AmapError 由 main.py 里注册的全局异常处理器统一转成 502 响应
    pois = amap.search_poi(keywords, city, limit)
    return ApiResponse(data=pois, message=f"找到 {len(pois)} 个结果")
```

```python
"""地图相关接口：天气"""

from typing import Annotated

from fastapi import APIRouter, Depends, Query

from app.models.schemas import ApiResponse, WeatherInfo
from app.services.amap_client import AmapClient, get_amap_client

router = APIRouter(prefix="/map", tags=["地图"])


@router.get("/weather", response_model=ApiResponse[list[WeatherInfo]], summary="天气预报")
def get_weather(
    city: Annotated[str, Query(min_length=1, description="城市名或 adcode")],
    amap: AmapClient = Depends(get_amap_client),
):
    return ApiResponse(data=amap.get_weather(city))
```

### `def` 还是 `async def`？这是 FastAPI 最容易踩的坑

| 路由写法 | 里面调用的代码 | 结果 |
|---|---|---|
| `def` | 同步阻塞（`httpx.Client`、`time.sleep`、大部分 SDK） | ✅ FastAPI 自动放进线程池执行 |
| `async def` | 异步代码（`await httpx.AsyncClient().get()`） | ✅ 在事件循环里执行，并发效率最高 |
| `async def` | **同步阻塞代码** | ❌ **阻塞整个事件循环，所有请求都卡住** |

前端类比：Node 里写 `fs.readFileSync` 会阻塞整个进程，`async def` 里调用同步代码是同一个问题。**拿不准时就用 `def`**，这是最安全的写法。参考仓库的 `trip.py` 用 `async def` 调用了同步的 Agent，就踩了这个坑（第 11 课会修）。

1. 导入部分：


2. 在 `app.add_middleware(...)` 之后、`include_router` 之前，加上全局异常处理器：

```python
# ---------- 全局异常处理器 ----------
# 任何路由里抛出 AmapError，都会被这里接住，转成 502 + {"detail": "..."}
# 和 Express 的错误处理中间件 app.use((err, req, res, next) => ...) 是一个思路：
# 路由只管业务，错误格式在一处统一
@app.exception_handler(AmapError)
async def handle_amap_error(request: Request, exc: AmapError):
    return JSONResponse(status_code=502, content={"detail": str(exc)})
```

3. 注册新路由：

```python
app.include_router(poi.router, prefix="/api")
app.include_router(map_routes.router, prefix="/api")
```

> 返回格式用的是 `{"detail": "..."}`，和 FastAPI 自带的 `HTTPException` 保持一致，所以前端第 4 课写的 `toErrorMessage` 不用改，就能直接显示这条错误。
